# PassaAqui Mobile Flutter

---

## Pré-requisitos

- **Flutter SDK** — [Guia oficial de instalação](https://docs.flutter.dev/get-started/install)
- **Editor de código** — VS Code com extensão Flutter e Dart, ou Android Studio
- **Emulador Android** — Android Studio > Device Manager, ou dispositivo físico com depuração USB
- **Git**

---

## Verificando o ambiente

```bash
flutter doctor
```

---

## Clonando o repositório

```bash
git clone <URL_DO_REPOSITORIO>
cd <NOME_DA_PASTA>
```

---

## Instalando as dependências

```bash
flutter pub get
```

---

## Rodando o projeto

```bash
flutter run
```

---

## Verificando o código

```bash
flutter analyze
```
